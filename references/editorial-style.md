# 通识丛书 · 写作约定

版本 v2，2026-11-05。依据试点反馈与实际产能修订：目标字数由 2500 调整为 4200，章节数相应放宽。写作流程与人工写作都以本文件为准；与本文件冲突的旧习惯作废。

## 一、篇幅与节奏

- 全文 4000–4500 汉字，目标 4200，其中正文主体不少于 4000 字。统计口径是汉字数，不含标点、空格、数字和英文；术语表与延伸阅读计入全文但不计入正文主体，合计不超过 300 字。命令见第九节。
- 术语表与延伸阅读不计入正文，两者合计不超过 300 字。
- 按每分钟 450 字算，4200 字约 9 分半。超过 4500 字必须删内容，不靠压句子凑数。
- 10–15 节，主体每节 200–450 字；开场和尾声可略短，但不少于 170 字。一节只推进一个意思。节标题用具体场景或小悬念，不用"背景""概述""结论"。
- 全篇至少两处减速：一处具体场景（有人、有时间、有地点、有动作），一处机制解释。其余部分保持推进。
- 试点超标的根源是这几类内容，新稿优先删：同一论点的第二次总结、五个以上平行要点的罗列、为求完整补的旁支（第三例证、第四个反驳）、上下文已经能看懂的术语。

## 二、选题：先找题眼

用三个问题筛题，命中两条才算通过：

1. 一句话讲给朋友听，他会不会追问"然后呢"？
2. 标题里能不能放进一个具体名词或数字，而不是一个抽象范畴？
3. 有没有反常识的落点——读者原以为 A，材料指向 B？

可用的题眼类型：

- 物件反推：一枚钱币、一份菜单、一张地图，如何暴露一整套制度。
- 身份错位：一个被记住的人，其实被记错了身份或角色。
- 技术副作用：为甲目的发明的东西，怎样改写了乙领域。
- 单位之争：度量衡、历法、货币单位背后谁说了算。
- 缺口：档案、注脚、译本里被删掉或漏掉的那一段。
- 偶然幸存：一件器物或一份文书活下来，靠的是哪几个巧合。

直接淘汰：百科条目式选题（"某事物的历史"）、单一事件复述、已经烂熟的科普梗（庞贝末日、图坦卡蒙诅咒、特斯拉与爱迪生）、找不到一手材料支撑的都市传说。

差异化检查：领域按八域轮转，题眼类型也不得与近三期重复。同一领域再写，切入点必须换——不能连续两期都是"灾难加气候"这类结构。

## 三、开头：前 150 字必须有钩子

四种开场选一种，不要叠加：

1. 实物开场：一件具体的东西，放在具体的地方，带一个说不通的细节。
2. 场景开场：某人在某时做了一件小事，这件小事后来变得要紧。
3. 数字开场：一个精确到反常的数字，先让读者觉得"这也能算"。
4. 断言开场：一句流行说法，紧接着指出它站不住的地方。

硬性要求：

- 第一段不超过 120 字，第二段结束前必须让读者知道"为什么值得看"。
- 不写"在人类历史的长河中""自古以来""提到某某，很多人会想到"。
- 开头不交代全文结构，不写"本文将从三个方面"。
- 第一段不出现"本文将""笔者认为"。

## 四、讲故事的分寸：三分材料

每处材料都要能归入下面三类之一，并且让读者从文字上看出区别：

- 一手记载或实物：直接写"某人在某书写道""这枚钱币上刻着"，可以当叙述骨架。
- 后世转述或传说：必须带来源标签，如"十二世纪的编年史这样讲""民间流传的版本是"，并说明它和更早材料的关系——补充、变形，还是矛盾。
- 现代推断：写"研究者推测""按目前的重建""一种解释是"。

具体手法：

- 传说可以讲得生动，但讲完要交代可信度，例如"这个故事最早出现在事件两百年后，此前的材料里没有"。
- 人物心理和对白只能以"据某书记载"的形式转述；没有出处的对白一律不写。
- 不用"据说"当万能挡箭牌。写了"据说"，附近就要说明据谁、何时说。
- 不做悬念式造假：不能先写"真相令人震惊"，再说其实是常规现象。
- 数字给区间或加限定词（"约""前后""量级"），不把估计值写成精确值。

## 五、趣味但不轻浮

可以：

- 用具体细节造画面：气味、价格、重量、耗时、当事人的抱怨。
- 用短促的转折调节奏，把宏大叙述落回一个人的处境。
- 适度幽默，对象是处境、制度或文本的荒诞，不是受害者。
- 用一次第二人称假设（"如果你是当时管账的人"），全篇不超过一次。

不可以：

- 拿死亡、疾病、灾难中的受害者开玩笑，不写"活该""荒诞到好笑"这类判断。
- 堆网络流行语和夸张比喻（"逆天""封神""降维打击"）。
- 为有趣牺牲准确：不编细节、不虚构引文、不给传说加戏。
- 通篇抖机灵。趣味是节奏调料，每 600–800 字出现一处即可，其余靠事实本身的密度撑住。
- 说教式收尾。删掉"这告诉我们""由此可见""值得深思"，把结论交给事实，最多留一句具体追问。

## 六、分析放在哪里

- 解释性段落全篇不超过三处，每处 150–250 字，紧跟在一段具体材料之后，作用是把材料接上机制或背景。
- 解释跟着材料走：先给现象，再给原因，最后给一个可检验的推论。
- 不用"第一、第二、第三"式清单说理。需要并列时，用两三个短段自然展开。
- 观点要有承担：写"目前更站得住的说法是甲，因为乙"，而不是只写"学界有不同看法"。
- 不确定就说清楚缺哪一环证据，不用"有待进一步研究"敷衍。

## 七、结尾与确定性说明

倒数第二节固定为"确定性说明"，分三档，每档 2–4 条，每条一句话，写明证据类型（铭文、档案、考古地层、实验数据），不写笼统的"相关研究"：

- 可以确认的：有一手证据、学界基本无争议。
- 有共识但细节存疑的：方向明确，数值、范围或地点有争议。
- 属于推测或仍有争论的：写清这是推测、谁在争、争的是什么。

最后一节用 100–150 字收束，给一个能带走的具体问题或一个对照，不喊口号，不升华到"人类文明"。

若文中纠正了某个流行说法，确定性说明里要单列一条，写清它错在哪。

文末保留术语表（3–5 条，每条 40 字以内）和延伸阅读（3–5 条，出处可核查，标注作者、篇名、出处或年份）。

## 八、语言与格式

- 中文全角标点。数字用阿拉伯数字。年份写"公元 536 年"，世纪写法全篇统一（"六世纪"或"6 世纪"）。
- 外国人名首次出现给中文译名并附原文，之后只用中文；同一人物不换译名。
- 段落 3–5 句，单段不超过 200 字。
- 标题层级：`#` 篇名，`##` 节标题。节标题 4–12 字，可以带冒号。
- 引文加引号并注明出处；核不实的引文不写。
- 归档沿用 `YYYY-MM-DD-短标题/article.md`，标题避免空格和特殊符号。

## 九、交付前自检

逐条打勾，任何一条不过就改：

- [ ] 全文汉字数在 4000–4500 之间、正文主体不少于 4000 字，并贴出统计结果
- [ ] 10–15 节，单节 200–450 字，开场和尾声不少于 170 字
- [ ] 第一段 120 字内，有一个具体钩子
- [ ] 至少两处具体场景，解释段不超过三处
- [ ] 每处传说或后世材料都标了来源和可信度
- [ ] 没有编造的对白、引文、细节
- [ ] 没有"这告诉我们""由此可见"类说教句
- [ ] 确定性说明三档齐全，条目具体
- [ ] 术语表不超过 5 条，延伸阅读 3–5 条且可核查
- [ ] 通读一遍，计时 9–10 分钟
- [ ] 与近三期在领域和题眼类型上都不重复

字数统计（PowerShell，统计汉字数）：

```powershell
$t = Get-Content -LiteralPath .\article.md -Raw -Encoding UTF8
([regex]::Matches($t, '[\u4e00-\u9fff]')).Count
```

## 十、写作流程的读取顺序

每次备稿按固定顺序执行：

1. 读 `index.md`，确认八域轮转、已写清单，避开近三期重复的领域与题眼类型。
2. 读 `STYLE.md` 全文，按第九节自检清单逐条核对。
3. 选题、写作、归档，并更新索引的"已写"表。

没读 STYLE.md 不得开始写作；自检未过，稿件不得进入待发库存。
